Sunhaven Streets — a sun-soaked 2D top-down open-world crime game, built from scratch for make.fun's "Make GTA 6" bounty. You are Alex Vega, a driver new in the coastal city of Sunhaven with a debt to clear. Explore a living city on foot and by car, steal cars, outrun the Sunhaven police across a 5-star wanted system, fight the Red Tide gang, and run 5 story missions — from your first stolen wheels to the big bank score — to become the King of Sunhaven.

The game includes a full open world (road grid, buildings, parks, beach and bay, traffic AI, pedestrians), car theft and arcade driving, police chases with arrests, fist and pistol combat, a HUD with health, money, wanted stars and a live minimap, synthesized WebAudio sound effects and music (no audio files, no network), a start screen, pause, and localStorage saves. Everything is original: our own city, characters, story, art and sounds.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD move / drive · E enter or exit a car (steal it) · F punch · G shoot (aim with the mouse) · Shift run · P pause · H save · C continue a saved game · M mute music. Or open `game/index.html` from any static server — the game is plain static files with no build step and no network requests.
